# 📌 Reflection: Agile User Stories & Sprint Planning  

## 1. Challenges in Prioritization  
One of the main challenges was ensuring that high-priority tasks were **aligned with stakeholder needs**. For example, attendance tracking is a **must-have** because it is the core function of the system. However, exporting reports, while useful, is not critical in early sprints.  

## 2. Difficulties in Effort Estimation  
Estimating effort in **Story Points** was challenging because some tasks were **dependent on others** (e.g., the attendance module relies on user authentication). The Fibonacci sequence (1, 2, 3, 5) helped us **avoid underestimating complex tasks**.  

## 3. Aligning Agile with Stakeholder Needs  
Since I am the only stakeholder at this point, I had to **play multiple roles** (Product Owner, Developer, Tester). This created a unique challenge because I had to **balance technical feasibility with usability concerns**.  

## 4. Lessons Learned  
- Agile helps **break complex problems into smaller, manageable tasks**.  
- Prioritization ensures that **core functionality is developed first**.  
- Effort estimation is **a skill that improves over time**.
