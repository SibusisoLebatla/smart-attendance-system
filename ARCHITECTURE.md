## Project Title: Smart Attendance Sysytem

## Domain: System Management System

##Problem Statement
The University has had problems about the students that signs for each other while others are absent so solution was to create a system to solve this. The systems is gdesigned to help the University to track the attendance of students using QR code or facial recognition. 

##Indivisual Scope
Includes: 
* Web interface for both the lectures and administrators
* Real-time attendance tracking and reporting
* Secure database srtorage
* A QR code generator for both students and lecturers
