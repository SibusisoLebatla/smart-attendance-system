# Reflection

## Challenges in Selecting and Customizing the Template
One of the challenges I faced was deciding between the **Automated Kanban** and **Team Planning** templates. While **Team Planning** offers more columns and could be better for larger teams, the **Automated Kanban** template aligns better with my project’s needs. The automation provided in the **Automated Kanban** template makes it easier to track the progress of tasks and manage the workflow without manual intervention.

## Comparison with Other Tools (e.g., Trello, Jira)
Compared to tools like **Trello** and **Jira**, GitHub’s Kanban board is relatively simple. **Trello** is more flexible and user-friendly, allowing for a lot of customization, but lacks deep integration with development workflows. **Jira**, on the other hand, offers more powerful Agile tools like sprint planning, burndown charts, and backlog management, which are more suitable for larger teams and more complex projects. GitHub’s Kanban board is a good compromise for smaller teams who are already using GitHub for version control.

## Lessons Learned
Through this exercise, I learned the importance of adapting tools to suit the size and complexity of the project. The **Automated Kanban** template helps streamline task management without requiring a lot of manual intervention, which saves time and reduces errors. However, I also realized that in larger projects, tools like **Jira** or **Trello** would offer more features for better tracking and reporting.
