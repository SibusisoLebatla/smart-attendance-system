# 🏫 Smart Attendance System - Stakeholder Analysis

## **📌 Overview**
The **Smart Attendance System** involves multiple stakeholders with different interests and concerns.  
The following table outlines each stakeholder, their role, key concerns, pain points, and success metrics.

| Stakeholder | Role | Key Concerns | Pain Points | Success Metrics |
|-------------|------|-------------|-------------|----------------|
| **Students** | Use the system to register attendance via QR code or Face ID | Quick and hassle-free attendance marking | Forgetting to check in, system lag | Attendance marked within 2 seconds |
| **Teachers** | Monitor student attendance and generate reports | Accurate data, easy-to-use interface | Manual checking is time-consuming | Reduce manual attendance effort by 50% |
| **Administrators** | Manage users, approve registrations, and oversee system | Security, user management | System downtime, difficult maintenance | 99.9% system uptime |
| **IT Support Staff** | Maintain and troubleshoot the system | System stability and performance | Technical issues, security vulnerabilities | Response time under 10 minutes |
| **University Management** | Use reports to analyze student attendance trends | Reliable and detailed analytics | Incomplete or inconsistent data | Generate reports with 95% accuracy |
| **Parents/Guardians** | Monitor student attendance | Get real-time updates | No visibility on absenteeism | Automated SMS notifications within 1 min |
