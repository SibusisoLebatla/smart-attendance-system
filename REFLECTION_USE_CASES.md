# Reflection  

### Challenges Faced  
1. **Understanding Stakeholder Needs**: Balancing student, admin, and faculty requirements was complex.  
2. **Defining Functional & Non-Functional Requirements**: Some system behaviors overlapped, requiring clarity.  
3. **Developing Test Cases**: Ensuring each function was testable required additional effort.  
4. **Mermaid.js Formatting Issues**: Fixing syntax errors for rendering diagrams correctly.  
5. **Performance Testing**: Simulating concurrent users was challenging without proper load testing tools.  

### Lessons Learned  
- Using structured methodologies simplifies requirement analysis.  
- Test-driven development improves system reliability.
