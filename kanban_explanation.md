# Kanban Board Explanation

## What is a Kanban Board?
A **Kanban board** is a visual tool used to manage and visualize workflows. It uses columns to represent the various stages that tasks go through in their lifecycle. These columns help track the progress of tasks from start to finish.

## How Does the Board Visualize Workflow?
The board uses columns to represent task progress:
- **To Do**: Tasks that need to be done.
- **In Progress**: Tasks that are being worked on.
- **Testing**: Tasks that are in the testing phase.
- **Blocked**: Tasks that cannot proceed due to issues.
- **Done**: Tasks that have been completed.

## How the Board Limits Work-in-Progress (WIP)
To ensure smooth and efficient workflow, we limit the number of tasks in each column. This helps avoid overloading and ensures that the team remains focused on the most important tasks without feeling overwhelmed.

## How It Supports Agile Principles
- **Continuous Delivery**: Tasks move through the board in stages, making it easier to release features incrementally.
- **Adaptability**: The board is flexible and can easily be updated based on the changing needs of the project.
- **Visibility**: It provides a real-time view of the progress and status of each task, making it easier for everyone involved to stay on track.
